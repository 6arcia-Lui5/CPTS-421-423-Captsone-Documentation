# Digital Humanities Data Mining & Visualization

## Project summary

### One-sentence description of the project

Digital Humanities Data Mining & Visualization is a web-based platform that allows authorized users to submit, search, convert, and collaboratively manage artifact records, providing a standardized, reliable, and accessible resource for researchers, educators, and hobbyists.

### Additional information about the project

Digital Humanities Data Mining & Visualization is an innovative web platform designed to transform artifact research by unifying fragmented databases, enabling collaborative record submission, and providing powerful search and visualization tools. The platform supports refined manual record importing, batch record uploading, and Express-to-JSON conversion to streamline the process of managing and processing artifact data. It helps researchers, educators, and hobbyists uncover historical insights faster and more accurately, while also bridging gaps in knowledge about inscriptions, correcting translation errors, and shedding light on the craftsmen behind the artifacts.

## Functionality

The platform provides several features for managing and working with artifact records:

- **Search functionality:** Users can search existing artifact records to quickly locate relevant information.
- **Express-to-JSON conversion:** Records can be processed through Express and converted into JSON format for standardized data handling.
- **Batch record uploading:** Multiple records can be uploaded and processed at once, making it easier to work with larger datasets.
- **Manual record importing:** The manual record-importing workflow has been refined to provide a more streamlined process for adding individual records.
- **User authentication:** Login functionality restricts access to authorized users. The current implementation supports a maximum of 5 designated users as a temporary limitation.
- **Web hosting:** The application is hosted on Vercel and is accessible through its deployed web application.
- **Artifact record management:** Users can submit and collaboratively manage standardized artifact records.
- **Search and visualization:** Users can explore artifact information through search and visualization tools designed to support research and analysis.
