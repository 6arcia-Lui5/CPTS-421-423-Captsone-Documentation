# CPT_S 421: Senior Software Project Report

This project is a full-stack web application that allows users to create, manage, and explore structured records within a centralized system. The platform supports user authentication, enabling individuals to securely access and manage their own data.

The application is built using a modern tech stack, with a React-based frontend for dynamic user interaction, a Node.js/Express backend for handling application logic and API requests, and a PostgreSQL database for persistent data storage.

The system follows a client-server architecture, where the frontend communicates with backend APIs to retrieve and modify data. Overall, the project demonstrates core software engineering principles, including modular design, separation of concerns, and full-stack integration.
